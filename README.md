# MBO Solutions — сайт-портфоліо

Статичний односторінковий сайт студії **MBO Solutions** (mbo-solutions.com). Без збірки та залежностей: HTML + CSS + JS.

## Структура

```
index.html            — головна (Hero, Послуги, Кейси, Ціни, Корисне, Квіз, Про нас, FAQ, Контакти)
calculator.html       — калькулятор вартості й окупності (ціни — у js/calculator.js, блок TYPES/OPTIONS)
audit.html            — безкоштовний експрес-аудит
examples/             — «Сайт для вашого бізнесу»: index + демо detailing / sto / beauty / tires (noindex)
guides/               — гайди: Google Maps, сайт автосервісу, шапка Instagram
privacy.html          — політика конфіденційності
css/style.css         — спільні стилі; css/pages.css — підсторінки; css/demo.css — демо-сайти
js/main.js            — анімації, меню, форми (будь-яка <form data-lead-form>), трекінг
js/config.js          — ID Google Ads / Analytics (для всіх сторінок)
tools/pages/          — генератор підсторінок (на сервері закритий через .htaccess)
assets/               — зображення, шрифти, іконка
```

### Як змінювати підсторінки

Шапка, логотип і футер підсторінок копіюються з `index.html`. Тексти — у `tools/pages/gen_*.py`. Після змін:

```bash
python3 tools/pages/build.py
```

## Анімації та ефекти

- прелоадер з логотипом (показується один раз за сесію);
- поява заголовків по словах, інтро першого екрана, «шторка» для зображень;
- частинки на фоні hero, 3D-нахил макета з відблиском і рамкою, що обертається;
- світіння за курсором, підсвітка карток за мишею, «магнітні» кнопки;
- бігучі стрічки з послугами, лінія прогресу етапів роботи, кільце прогресу на кнопці «вгору».
- квіз «Підберемо рішення» (секція `#quiz`) — тексти рекомендацій у `js/main.js` (PRODUCTS, BRAND, TIMING);
- блок «Цей сайт — наш доказ» з оцінкою швидкості (секція `#proof`), плаваюча кнопка Telegram;
- пасхалка: набрати на клавіатурі «mbo» або 5 разів швидко натиснути на логотип.

Якщо в системі ввімкнено «зменшити рух» (prefers-reduced-motion), анімації вимикаються.
Повторно побачити прелоадер можна в новій вкладці або після `sessionStorage.clear()`.

## Локальний запуск

```bash
python3 -m http.server 8000
# відкрити http://localhost:8000
```

## Що замінити перед запуском

- **Контакти** (`index.html`, секція `#contact`): email `hello@mbo-solutions.com`, посилання на Telegram та Instagram.
- **Email для форми** — константа `EMAIL` у `js/main.js`. Форма зараз відкриває поштовий клієнт із готовим листом; для прийому заявок без пошти можна підключити Formspree, Telegram-бота тощо.
- **Ім’я засновника** — підпис у секції `#about` («Засновник MBO Solutions»).
- **Новий кейс** — скопіюйте блок `<article class="case">` у секції `#cases`.

## Google Реклама та аналітика

ID вписуються в одному місці — файл `js/config.js` (діє на всіх сторінках). Після зміни збільшіть `?v=` у підключенні `js/config.js?v=…` (index.html та `tools/pages/common.py` → `build.py`).

| Поле | Що це | Де взяти |
|---|---|---|
| `adsId` | ID акаунта Google Ads (`AW-…`) | Google Ads → Цілі → Конверсії → дія → «Налаштувати тег» |
| `leadLabel` | мітка конверсії «Заявка з сайту» | там само, частина після `/` у `send_to` |
| `callLabel` | мітка конверсії «Дзвінок / Viber / Telegram» | окрема дія-конверсія (необов’язково) |
| `ga4Id` | Google Analytics 4 (`G-…`) | Analytics → Адміністратор → Потоки даних (необов’язково) |

Поки поля порожні — скрипти Google не завантажуються взагалі. Що рахується:

- **Заявка** — надсилання форми контактів або квізу (`generate_lead` + конверсія `leadLabel`);
- **Контакт** — натискання на телефон, Viber, Telegram, email, Instagram (`contact` + конверсія `callLabel`).

Скрипт Google вантажиться після завантаження сторінки, тож не впливає на швидкість. Мітки рекламного переходу (`gclid`, `utm_*`) зберігаються на час візиту й додаються в лист із заявкою рядком «Джерело».

Також є `privacy.html` (політика конфіденційності — потрібна Google для сайтів із формами), `robots.txt` і `sitemap.xml`.

## Оптимізація

- для телефонів (до 600px) завантажуються зменшені зображення `*-sm.webp`;
- `.htaccess` вмикає стиснення, кешування та ховає папку `.git` на хостингу;
- CSS і JS підключені з версією (`style.css?v=5`). **Після зміни CSS/JS збільшіть номер `v`** в `index.html`, інакше відвідувачі бачитимуть стару версію з кешу.

## Публікація

Підходить будь-який статичний хостинг: GitHub Pages, Netlify, Vercel, Cloudflare Pages. Для GitHub Pages: Settings → Pages → гілка з сайтом, корінь `/`, потім додайте свій домен `mbo-solutions.com`.
