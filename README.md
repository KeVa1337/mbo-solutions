# MBO Solutions — сайт-портфоліо

Статичний односторінковий сайт студії **MBO Solutions** (mbo-solutions.com). Без збірки та залежностей: HTML + CSS + JS.

## Структура

```
index.html          — уся сторінка (секції: Hero, Послуги, Кейси, Чому MBO, Процес, Про нас, FAQ, Контакти)
css/style.css       — стилі (кольори та розміри в змінних :root)
js/main.js          — меню, анімації появи, активний пункт меню, форма заявки
assets/img/         — зображення (WebP) та og-image.jpg для соцмереж
assets/favicon.svg  — іконка сайту
```

## Анімації та ефекти

- прелоадер з логотипом (показується один раз за сесію);
- поява заголовків по словах, інтро першого екрана, «шторка» для зображень;
- частинки на фоні hero, 3D-нахил макета з відблиском і рамкою, що обертається;
- світіння за курсором, підсвітка карток за мишею, «магнітні» кнопки;
- бігучі стрічки з послугами, лінія прогресу етапів роботи, кільце прогресу на кнопці «вгору».

Якщо в системі ввімкнено «зменшити рух» (prefers-reduced-motion), анімації вимикаються.
Повторно побачити прелоадер можна в новій вкладці або після `sessionStorage.clear()`.

## Локальний запуск

```bash
python3 -m http.server 8000
# відкрити http://localhost:8000
```

## Що замінити перед запуском

- **Контакти** (`index.html`, секція `#contact`): email `hello@mbo-solutions.com`, посилання на Telegram та Instagram.
- **Email для форми** — константа `EMAIL` у `js/main.js`. Форма зараз відкриває поштовий клієнт із готовим листом; для прийому заявок без пошти можна підключити Formspree, Telegram-бота тощо.
- **Ім’я засновника** — підпис у секції `#about` («Засновник MBO Solutions»).
- **Новий кейс** — скопіюйте блок `<article class="case">` у секції `#cases`.

## Оптимізація

- для телефонів (до 600px) завантажуються зменшені зображення `*-sm.webp`;
- `.htaccess` вмикає стиснення, кешування та ховає папку `.git` на хостингу;
- CSS і JS підключені з версією (`style.css?v=5`). **Після зміни CSS/JS збільшіть номер `v`** в `index.html`, інакше відвідувачі бачитимуть стару версію з кешу.

## Публікація

Підходить будь-який статичний хостинг: GitHub Pages, Netlify, Vercel, Cloudflare Pages. Для GitHub Pages: Settings → Pages → гілка з сайтом, корінь `/`, потім додайте свій домен `mbo-solutions.com`.
